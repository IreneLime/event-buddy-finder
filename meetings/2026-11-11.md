Events: GET /events (search, filters, pagination), GET /events/:id, POST /events, PATCH /events/:id, and PUT /events/:id/participation with interested, going, or withdrawn.
Event attendance: GET /events/:id/participants for the people list or count, and GET /me/events for a user’s event history.
Profiles: GET /me/profile, PUT /me/profile, and—if public profile browsing is in scope—`GET /users/:id`.
Chats: GET /me/conversations, GET /conversations/:id/messages, and message sending through the chat service and Socket.IO. Joining an event chat should mark the user interested; it doesn’t need a separate “update group chat” endpoint.
Notifications: GET /me/notifications for saved alerts. Socket.IO delivers new alerts while the user is online.
Images: Add an event/profile image upload route when you start the DigitalOcean Spaces integration.
